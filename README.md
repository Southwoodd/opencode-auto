# OpenCode Auto — автовыбор модели в OpenCode

**Auto** — это плагин для [OpenCode](https://opencode.ai), который сам выбирает модель под задачу. В списке моделей появляется пункт **Auto**: выбрал его один раз — и дальше не думаешь, какую модель ставить для каждого сообщения.

- Простой вопрос или короткая правка — уходит в быструю дешёвую модель.
- Обычная рабочая задача — в среднюю.
- Архитектура, миграция, сложный баг, исследование — в сильную.

Цель простая: качество там, где оно нужно, и экономия там, где сильная модель не даёт ничего лишнего.

## Как это работает

Плагин смотрит на каждое твоё сообщение и оценивает его сложность по понятным признакам: длина, есть ли код, есть ли стек-трейс, сколько файлов приложено, есть ли слова вроде «спроектируй», «миграция», «рефакторинг», «найди причину» и т.п.

- **Бесплатные модели OpenCode** (`opencode/*-free`): выбор делается на **каждое сообщение** отдельно. Сказал «привет» — ответит быстрая модель, в следующем сообщении попросил спланировать миграцию — подключится сильная, потом снова короткий вопрос — снова быстрая. На бесплатных моделях это не стоит денег, только чуть-чуть времени на переключение.
- **Платные модели** (через свой ключ/провайдер): модель выбирается **на сессию** и не прыгает туда-сюда, потому что переключение на платной модели заставляет её заново перечитывать весь диалог — а это деньги. Если задача внезапно стала сильно сложнее (появилась архитектура, стектрейс и т.п.), плагин может перейти на более сильную модель, но обратно не откатывает.

Для совсем неоднозначных сообщений можно подключить быстрый классификатор (одна маленькая проверка дешёвой моделью). Без него всё работает на простых правилах и не делает лишних запросов.

## Установка

Нужен установленный [OpenCode](https://opencode.ai). Дальше — три шага, всё делается копированием текста в один файл.

### Шаг 1. Открыть файл настроек

Файл настроек OpenCode называется `opencode.jsonc` (или `opencode.json`) и лежит здесь:

- **Windows:** `C:\Users\ВАШЕ_ИМЯ\.config\opencode\opencode.jsonc`
- **macOS / Linux:** `~/.config/opencode/opencode.jsonc`

Если файла нет — создай его.

### Шаг 2. Вставить настройки

Скопируй этот блок в файл настроек. Если в файле уже что-то есть — добавь недостающие куски внутрь, не удаляя своё.

```jsonc
{
  "$schema": "https://opencode.ai/config.json",

  "providers": {
    "opencode": {
      "models": {
        "auto": {
          "name": "Auto",
          "description": "Автовыбор модели по сложности задачи"
        }
      }
    }
  },

  "plugins": [
    {
      "package": "github:Southwoodd/opencode-auto"
    }
  ]
}
```

Что здесь что:
- `providers.opencode.models.auto` — добавляет пункт **Auto** в список моделей (в группе бесплатных моделей OpenCode). Без этой строчки пункта в списке не будет.
- `plugins` — подключает сам плагин с GitHub. Настраивать ничего не нужно: по умолчанию он уже умеет выбирать между бесплатными моделями OpenCode.

### Шаг 3. Выбрать Auto

Перезапусти OpenCode (или просто подожди пару секунд, он подхватывает изменения). Открой выбор модели (`/models` или `Ctrl+X`, затем `M`) и выбери **Auto** в группе OpenCode. Готово.

Если захочешь выбрать конкретную модель вручную — просто выбери её как обычно. Auto работает только когда выбран именно он.

## Для платных моделей (необязательно)

Если у тебя подключён платный провайдер (например, через свой ключ) и ты хочешь, чтобы Auto выбирал и среди его моделей:

1. Добавь `auto` в модели этого провайдера, чтобы пункт появился в списке.
2. Опиши, какую модель брать для простых/обычных/сложных задач.

Пример:

```jsonc
{
  "providers": {
    "opencode": {
      "models": {
        "auto": { "name": "Auto", "description": "Автовыбор модели" }
      }
    },
    "proxyapi": {
      "name": "Мой провайдер",
      "models": {
        "auto": { "name": "Auto", "description": "Автовыбор модели" }
      }
    }
  },
  "plugins": [
    {
      "package": "github:Southwoodd/opencode-auto",
      "options": {
        "routes": {
          "opencode": {
            "strategy": "request",
            "simple": "deepseek-v4.1-flash-free",
            "standard": "mimo-v2.6-flash-free",
            "complex": "longcat-2.5-free"
          },
          "proxyapi": {
            "strategy": "session",
            "simple": "z-ai/glm-5.3",
            "standard": "openai/gpt-6.2-sol",
            "complex": "anthropic/claude-opus-5-5"
          }
        }
      }
    }
  ]
}
```

Важно: Auto выбирает модель **только внутри того провайдера, которого ты выбрал**. Перепрыгнуть с бесплатного OpenCode на платный ProxyAPI внутри одного ответа он не может — это ограничение самого OpenCode. Поэтому у каждого провайдера свой пункт Auto.

## Что важно знать

- **Переключение не бесплатно.** На платных моделях смена модели заставляет заново перечитывать весь разговор — поэтому для платных по умолчанию стоит режим «на сессию». На бесплатных это не про деньги, поэтому там режим «на каждое сообщение».
- **Первое сообщение задаёт тон.** Если сессия началась с «привет», на платном провайдере она, скорее всего, поедет на простой модели до конца сессии. Если знаешь, что задача тяжёлая — скажи это сразу в первом сообщении.
- **Бесплатные лимиты — это не плагин.** У бесплатных моделей OpenCode есть свои лимиты. Если видишь «Free usage limit reached» — это кончилась квота конкретной модели у OpenCode, плагин тут ни при чём. Можно подождать, выбрать другую модель или подключить платного провайдера.
- **Модели меняются.** Если какая-то модель пропала из каталога, плагин попробует запасную из того же набора, чтобы не упасть.

## Если что-то не так

- **Auto не появился в списке** — проверь, что в `providers.<название>.models` есть блок `"auto": { ... }`. После правки файла подожди пару секунд.
- **Всегда выбирается одна и та же модель** — скорее всего, в маршруте для simple/standard/complex указана одна и та же модель. Это нормально, если так и задумано.
- **Плагин не подхватился** — проверь, что в `plugins` есть `{ "package": "github:Southwoodd/opencode-auto" }` и интернет доступен при первом запуске (плагин качается с GitHub).
